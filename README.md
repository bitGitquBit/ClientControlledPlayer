# ClientControlledPlayer
Moving a player on a server through client commands

To test:
1. Clone the git repo
2. Go to the repo folder
3. Run server.py in a terminal session (python server.py or python3 server.py)
4. Run client.py in a seperate terminal session (python client.py or python3 client.py)
5. server.py session shows player and board, client.py session allows you to move the player
